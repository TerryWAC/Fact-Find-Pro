# Brand artwork

Drop the Wealthy Advisers Club lion banner here as **`wealthy-advisers-club.png`**
(`.jpg` and `.webp` also work) and redeploy.

It is picked up at build time and used in:

- the sign-in / sign-up brand panel
- the dashboard sidebar
- the public client-facing FactFind pages
- the onboarding welcome screen

Until the file exists, a typographic "The Wealthy Advisers Club" lockup is
rendered in each of those places, so nothing looks unfinished.

Recommended: the wide 16:9 version (lion left, wordmark right) at around
1440×810, on a solid black background so it sits flush with the dark surfaces.
